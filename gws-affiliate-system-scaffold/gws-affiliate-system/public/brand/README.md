# Official GrowthWorks Systems artwork

`growthworks-logo.webp` uses the complete emblem and wordmark from the logo supplied by Jhed in this project. It replaces the previous remote-image dependency and generated text fallback.

The supplied 561 x 445 PNG was proportionally resized to 280 x 222 and web-optimized. A GWS cream backing preserves visibility of the original dark artwork on the dark page; no inversion, recoloring, stretching, or substitute mark is used. The header and footer share the same asset.

`../../src/app/favicon.ico` contains 16 x 16 and 32 x 32 icons derived from the supplied emblem, without the small wordmark. It uses the same cream backing for light/dark browser-tab legibility. Next.js serves this root App Router icon for the generic and affiliate routes.
